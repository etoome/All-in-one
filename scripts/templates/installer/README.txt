All-in-one for PowerPoint v@@VERSION@@

Install
1. Double-click Install.cmd. If Windows shows a security warning, choose "Run".
2. Follow the prompts. If PowerPoint is open, the installer waits until you close it.
3. Start PowerPoint. The "All-in-one" tab appears at the start of the ribbon.

It installs for your user only and does not need administrator rights.

Update
This add-in does not update itself. When a newer version is available, an "Update" group appears
at the start of the All-in-one tab and its button opens the download page on @@UPDATE_HOST@@.
Extract the newer zip from there to a new folder and run its Install.cmd. It replaces the old version.

Uninstall
Open a Command Prompt in this folder and run:

    Install.cmd -Uninstall

Then restart PowerPoint.
